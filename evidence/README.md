# Preserved scientific evidence

This directory contains immutable evidence bundles underlying scientific-model
iterations, annotation decisions and reported results. Each bundle has its own
manifest, integrity hashes, interpretation limits and distribution policy.

Do not silently update a frozen bundle. A correction or later adjudication must
create a new versioned bundle, preserve the earlier one, and document what was
superseded. Evolving interpretations belong in
[`docs/scientific-model/`](../docs/scientific-model/); operational annotation
rules belong in the annotation guidelines.

## Bundles

- [`T052/`](T052/README.md): final 60-case T052 review packet, complete
  annotation history, source pilot manifest, outcome summary and validated
  final BioC interchange.
- [`T057/`](T057/README.md): frozen T056/T057 assisted-development bundle with
  a named exact-pair projection, diagnostic challenge view, complete
  eligibility ledger and content-addressed acceptance corrections.
